# 📊 Sales Data Analyzer & Visualizer

A modular, interactive Python application built to streamline Exploratory Data Analysis (EDA), missing data handling, statistical summaries, and data visualization using `pandas`, `numpy`, `matplotlib`, and `seaborn`.

---

## 🛠️ Key Features

- **CSV Dataset Ingestion**: Load any standard CSV dataset with path validation.
- **Data Exploration**: View initial/final rows, column schemas, data types, and structural info.
- **Missing Data Management**: Identify null values, drop missing entries, impute missing numeric values using mean strategies, or replace them with custom values.
- **Mathematical & Statistical Analysis**: Perform vectorized NumPy array operations and generate standard statistical summaries (`describe()`).
- **Interactive Visualizations**:
  - Bar Plots
  - Line Plots
  - Scatter Plots
  - Pie Charts
  - Histograms with KDE overlays
  - Stack Plots
