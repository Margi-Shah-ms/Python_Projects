# 📔 Personal Journal Manager

A simple yet useful **Personal Journal Manager** built using **Python, OOP, File Handling, Exception Handling, and the Datetime module**.

This application allows users to maintain a digital journal where they can add, view, search, and delete journal entries through a menu-driven interface.

---

## ✨ Features

✅ Add new journal entries

✅ Automatically attach a timestamp to every entry

✅ View all saved journal entries

✅ Search entries using a keyword or date

✅ Delete all journal entries with confirmation

✅ Handle file-related errors gracefully

✅ User-friendly menu-driven interface

---

## 🛠️ Technologies Used

- Python 🐍
- Object-Oriented Programming (OOP)
- File Handling
- Exception Handling
- Datetime Module
- OS Module
