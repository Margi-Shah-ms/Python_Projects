# 🚀 Multi-Utility Toolkit

A Python-based command-line application that combines multiple useful utilities into a single toolkit. This project demonstrates the practical implementation of Python modules, file handling, date & time operations, mathematical calculations, random data generation, UUID generation, and menu-driven programming.

---

## 🌟 Features

### 🕒 Date & Time Operations

* 📅 Display current date and time
* ⏳ Calculate difference between two dates
* 📝 Format dates into custom formats
* ⏱️ Stopwatch
* ⌛ Countdown Timer

---

### 🧮 Mathematical Operations

* 🔢 Calculate Factorial
* 💰 Compound Interest Calculator
* 📐 Trigonometric Functions

  * Sine
  * Cosine
  * Tangent
* 📏 Area Calculations

  * 🔵 Circle
  * ▭ Rectangle
  * 🔺 Triangle

---

### 🎲 Random Data Generation

* 🎯 Generate Random Numbers
* 📋 Generate Random Lists
* 🔐 Create Random Passwords
* 📱 Generate OTPs

---

### 🆔 UUID Generation

* 🎫 Generate Random UUID4
* 📂 Generate UUIDs for Records, Files, or Sessions

---

### 📁 File Operations (Custom Module)

Using a custom `file_ops.py` module:

* 📄 Create Files
* ✍️ Write Data to Files
* 📖 Read File Contents
* ➕ Append Data to Existing Files

---

### 🔍 Module Exploration

* Explore module attributes using Python's `dir()` function

---
